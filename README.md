# CareerWrite – Online Job Portal

CareerWrite is a simple full-stack online job portal built using **Java, Spring Boot, MySQL, HTML, CSS, and JavaScript**.

The main purpose of this project is to provide a platform where job seekers can find and apply for jobs, while recruiters can post job openings and manage applications.

### Features

* User registration and login
* Browse and search available jobs
* View job details
* Apply for jobs
* View applied jobs
* Recruiter registration and login
* Post new job openings
* Manage posted jobs
* View applications
* REST APIs for frontend and backend communication
* MySQL database for storing application data

### Technologies Used

* **Backend:** Java, Spring Boot
* **Database:** MySQL
* **Frontend:** HTML, CSS, JavaScript
* **API:** REST API
* **Tools:** Git and GitHub

### Project Purpose

This project was created to gain practical experience in **Java backend development, Spring Boot, REST APIs, MySQL database connectivity, CRUD operations, and frontend-backend integration**.

The frontend uses JavaScript to communicate with the Spring Boot backend through REST APIs. MySQL is used to store users, jobs, and application-related information.

CareerWrite is designed as a simple and practical project that demonstrates the basic concepts of full-stack web development.
